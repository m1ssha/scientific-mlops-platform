# Архитектурные решения платформы

Все записи имеют статус **proposed**: они предназначены для обсуждения и не свидетельствуют о реализации или подтверждённых гарантиях. При пересмотре решения следует изменить его статус или подготовить новую запись со ссылкой на заменённую.

Уточнение от 9 ноября 2026 года: минимальный режим включает один проект, одного пользователя, HTTP API и простой веб-интерфейс истории, плана восстановления и сравнения. Полный цикл сначала проверяется через ядро и CLI, повторное выполнение доверенного пайплайна организует CLI или внешний скрипт. Многопользовательские права и отдельный исполнитель остаются расширениями. Статус записей сохранён.
