# Локальный интерфейс

Интерфейс - обратимый прототип при предложенных ADR. Он использует только локальный API, показывает сохранённые запуски, сравнение и план восстановления. Он не запускает пайплайн и не изменяет хранилище. Получение плана проверяет объявленные локальные объекты, а не воспроизводимость целиком. Для runtime, execution и numerical agreement значение unchecked означает отсутствие проверки.

Node.js 24.21.0 и npm 11.19.0 используются для сборки из зафиксированного package-lock.json. После npm ci и npm run build укажите web/dist/browser в необязательном аргументе --web-dir. Без аргумента работает только API. Сервер при запуске загружает разрешённые статические файлы в память, требует непустой index.html и отклоняет символические ссылки. Каталог интерфейса и хранилище не могут пересекаться. Скрытые файлы, source maps, списки каталогов и произвольные расширения не публикуются. Для обновления интерфейса перезапустите сервер. Файлы интерфейса и API защищены одинаковой проверкой Host и Origin, но это не аутентификация. API и интерфейс рассчитаны на доверенный локальный режим.

Последовательности API имеют тип int64, но браузер точно представляет только целые числа до 9007199254740991 включительно. Интерфейс отклоняет небезопасные значения последовательности и курсора вместо продолжения с округлёнными значениями. Для каталогов, превысивших этот предел, требуется изменение контракта представления чисел.
