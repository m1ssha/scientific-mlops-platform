# Scientific MLOps Platform

Проект платформы для просмотра истории ML-экспериментов и работы с результатами операций [Scientific MLOps Core](https://github.com/m1ssha/scientific-mlops-core). Платформа предназначена для доступа к данным экспериментов через HTTP API и веб-интерфейс; правила версионирования и восстановления относятся к ядру.

> [!IMPORTANT]
> Доступен локальный прототип API только для чтения существующего хранилища ядра. Веб-интерфейс и средства развёртывания пока не реализованы. Архитектурные решения остаются предложенными.

## Планируемый минимальный сценарий

Для одного проекта и одного пользователя платформа должна предоставлять:

- просмотр истории запусков и связанных с ними сведений;
- просмотр плана восстановления эксперимента;
- сравнение двух запусков.

Сначала эти операции предполагается проверить через ядро и CLI. По плану восстановления CLI или внешний скрипт подготавливает материалы и среду, выполняет один доверенный пайплайн и регистрирует новый запуск со ссылкой на исходный снимок. Само наличие плана не подтверждает успешное выполнение или совпадение результатов.

Многопользовательский доступ, управление правами и собственный исполнитель рассматриваются как дальнейшее развитие. Go и Angular, а также PostgreSQL, MinIO и Docker Compose для локального развёртывания - варианты для обсуждения, не утверждённый стек.
