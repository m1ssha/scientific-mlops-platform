# Scientific MLOps Platform

Проект платформы для работы с несколькими ML-исследованиями и участниками. Пока здесь находится архитектурный черновик: программная реализация и тема учебной работы ещё не утверждены.

Платформа управляет проектами, участниками, доступом, запуском экспериментов и представлением результатов. Правила версионирования и восстановления задаёт отдельный [Scientific MLOps Core](https://github.com/m1ssha/scientific-mlops-core). В первом учебном сценарии студент публикует данные и результаты, преподаватель просматривает и воспроизводит выбранный запуск.

Go и Angular рассматриваются как возможный стек. PostgreSQL, MinIO и Docker Compose - рабочий вариант локального прототипа, а не утверждённые требования. CLI может работать через тот же API, что и веб-интерфейс. MCP, HPC и отказоустойчивое развёртывание рассматриваются как возможные направления дальнейшей работы.
