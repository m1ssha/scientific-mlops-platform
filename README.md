# Scientific MLOps Platform

Проект платформы для представления истории ML-исследований и результатов операций ядра. Пока здесь находится архитектурный черновик с предлагаемыми решениями, а не описание реализованных гарантий.

Правила версионирования и восстановления задаёт отдельный [Scientific MLOps Core](https://github.com/m1ssha/scientific-mlops-core). Минимальный режим платформы включает один проект, одного пользователя, HTTP API и простой веб-интерфейс: история запусков, просмотр плана восстановления и сравнение двух запусков. Базовая аутентификация допустима. Несколько участников, управление правами и собственный исполнитель остаются расширениями.

Сначала проверяется полный цикл ядра и CLI без платформы. CLI или внешний скрипт по плану восстанавливает материалы, подготавливает среду, выполняет один доверенный пайплайн и регистрирует новый запуск со ссылкой на исходный снимок. Актуальные границы описаны в ADR, архитектурные схемы показывают также более широкий возможный состав.

Go и Angular рассматриваются как возможный стек. PostgreSQL, MinIO и Docker Compose - рабочий вариант локального прототипа, а не утверждённые требования. CLI может работать через тот же API, что и веб-интерфейс. MCP, HPC и отказоустойчивое развёртывание рассматриваются как возможные направления дальнейшей работы.
